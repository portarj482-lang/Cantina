# Solana / Anchor review checklist (disabled in EVM workflows)

- Pin program ID, source revision, cluster/ledger fixture, Anchor version, IDL digest, and dependency versions.
- Validate account ownership, signer requirements, writable flags, account constraints, PDA seeds/bump handling, and CPI target identity.
- Check token authority, mint/token-account relationships, SPL Token and Token-2022 behavior, checked arithmetic, lamport accounting, and conservation invariants.
- Use a local validator, Bankrun, or another approved isolated harness; do not reuse EVM assumptions or runner permissions.
- Treat IDLs and account schemas as inputs that require validation against actual program code and deployed target identity.
- The Solana cohort must remain disabled for EVM-only workflows and must have distinct tool allowlists, evidence types, and sandbox policy.
