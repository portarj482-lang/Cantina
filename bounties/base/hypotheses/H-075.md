# Hypothesis Evaluation: H-075

- **ID:** H-075
- **Target:** `OptimismPortal2` ([`contracts/src/L1/OptimismPortal2.sol`](file:///home/nova/projects/cantina/bounties/base/contracts/src/L1/OptimismPortal2.sol))
- **Actor:** Withdrawal caller / race condition adversary
- **Prediction:** When a dispute game resolves `DEFENDER_WINS` mid-window, an attacker can immediately call `finalizeWithdrawalTransaction` prior to the expiration of `proofMaturityDelaySeconds`, bypassing the mandatory delay window.
- **Status:** KILLED / REFUTED (Defensive Protocol Invariant Validated)
- **Kill Category:** PROOF_MATURITY_DELAY_AND_DISPUTE_FINALITY_SEPARATION
- **Date:** 2026-10-25

---

## 1. Hypothesis Formulation
The hypothesis queried whether:
1. Early resolution of a dispute game (`game.status() == DEFENDER_WINS`) allows an attacker to race finalization of a withdrawal.
2. `OptimismPortal2.finalizeWithdrawalTransaction` checks game resolution status before or instead of the explicit proof maturity timestamp check.
3. Replaying a finalized withdrawal transaction allows draining additional funds.

---

## 2. Invariant & Source Analysis

In `OptimismPortal2.sol`:
```solidity
function checkWithdrawal(WithdrawalTransaction memory _tx, address _proofSubmitter) public view {
    // ...
    // Checks that the dispute game was created before the withdrawal was proven.
    if (disputeGame.createdAt().raw() >= provenWithdrawal.timestamp) {
        revert OptimismPortal_InvalidProof();
    }

    // Checks that the dispute game claim is valid.
    if (!anchorStateRegistry.isGameClaimValid(disputeGame)) {
        revert OptimismPortal_InvalidGame();
    }

    // Checks that the proof has matured.
    if (block.timestamp < provenWithdrawal.timestamp + proofMaturityDelaySeconds) {
        revert OptimismPortal_ProofNotOldEnough();
    }
}
```

The protocol strictly enforces two independent checks:
1. `anchorStateRegistry.isGameClaimValid(disputeGame)`: Ensures the game has resolved defender wins and passed finality delay.
2. `block.timestamp >= provenWithdrawal.timestamp + proofMaturityDelaySeconds`: Even if the dispute game resolves immediately, the withdrawal cannot be finalized until the full `proofMaturityDelaySeconds` (e.g., 7 days) has elapsed.
