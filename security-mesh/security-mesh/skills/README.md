# Versioned skill drafts

All packs in this folder are **candidate/draft**, not trusted shared knowledge. They are human-authored starter checklists rather than evidence that a property holds in any particular deployed contract. Do not promote them to the approved retrieval collection until they have been checked against official documentation, positive and negative tests, source provenance, and reviewer feedback. Agent profiles identify version `1.0.0` for reproducibility, but this does not mean the packs are approved.

The current API does not yet implement skill-pack retrieval or promotion endpoints. PostgreSQL has the supporting schema for a later phase.
