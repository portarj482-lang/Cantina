# Universal Adaptive Intelligence Plugin

This plugin packages the **Universal Adaptive Intelligence Architecture** and **Universal Skill Adaptation Protocol (USAP)** into a unified Antigravity plugin bundle.

## Features
- **14-Stage Lifecycle Engine:** `INTAKE` through `COMPLETION_REPORT` with machine-validated handoffs.
- **USAP 5-Layer Adaptation:** Abstract security invariants decoupled from target language and repository structure.
- **Dynamic Manifest Resolution:** Coexisting multi-runtime discovery across EVM (Foundry/Hardhat), Solana (Anchor), Rust (Cargo), Move, and CosmWasm.
- **12 Specialist Agent Workflows:** Programmatic, inheritable classes with pre/post hooks and blocker recovery.
- **Domain Operation Pipelines:** Fault Dispute System, DelayedWETH Solvency, Multiproof TEE Attestation, and RPC Governance.
- **Independent Challenger Gates:** Adversarial negative controls, tampered digest falsification checks, and mathematical scalar boundary verification.

## Structure
- `skills/`: Core universal orchestration skills.
- `agents/`: 12 specialist persona manifests.
- `rules/AGENTS.md`: Universal engineering invariants and non-destructive audit guardrails.
